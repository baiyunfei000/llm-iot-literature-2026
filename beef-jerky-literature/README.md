# 牛肉风干制品加工技术文献库

这是一个静态 GitHub Pages 文献检索站，收录 72 篇与牛肉干、风干牛肉、Biltong、Pastirma 及牛肉干燥工程相关的同行评审论文。

## 数据范围

- 书目检索：Crossref REST API
- 摘要节选与被引快照补充：OpenAlex
- 检索快照：2026-10-23
- 原始候选：245 条去重题录
- 最终收录：72 篇，来自 24 个同行评审期刊

本站提供书目信息、短篇中文导读和摘要节选，不托管或分发论文全文。论文详情、方法、结果与讨论应以 DOI 指向的原文为准。

## 页面功能

- 标题、作者、期刊、DOI 和关键词搜索
- 六类研究主题、年份区间、技术标签和收藏筛选
- 年份、被引次数及标题排序
- 单篇 APA 风格引文、BibTeX、RIS 复制
- 当前筛选结果导出为 CSV 或 BibTeX
- 桌面端与移动端自适应

## 本地更新

站点可直接打开 `index.html`。重新生成结构化数据与下载文件：

```powershell
node scripts/build_data.mjs
```

`curation.json` 保存人工筛选顺序、主题、导读与标签；`data.js`、`papers.json`、CSV 和 BibTeX 由构建脚本生成。

## 说明

这是面向加工技术选题的专家筛选清单，不是 PRISMA 系统综述。候选池不保证覆盖所有数据库或所有语言。被引次数只是 Crossref/OpenAlex 的检索时点快照，不代表论文质量的单独判定。
