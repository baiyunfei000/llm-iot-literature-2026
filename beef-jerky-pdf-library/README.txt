牛肉风干制品开放全文精选
============================

在线使用
1. 打开 GitHub Pages 页面。
2. 在页面中搜索或筛选论文。
3. 点击“在线阅读 PDF”。

内容
- 15 篇完整论文 PDF，位于 pdfs 文件夹。
- 每篇论文的首页缩略图，位于 thumbs 文件夹。
- full-text-catalog.csv：文献目录。
- full-text-library.bib：BibTeX 引文库。
- catalog.md：纯文本版目录。
- catalog.json：结构化元数据。

说明
本站只收录已经成功下载并通过 PDF 文件头与页数验证的论文。未取得合法完整全文的条目已剔除。
PDF 来自出版社开放获取页面或明确可免费下载的期刊页面，不包含绕过付费墙的内容。
版权与再利用条件以各论文 CC BY、CC BY-NC 等许可和出版社条款为准。
