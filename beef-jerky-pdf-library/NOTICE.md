# 论文来源与许可说明

本站仅收录可从出版社开放获取页面下载的完整论文。每篇 PDF 的版权属于原作者和出版机构。

- CC BY 论文允许在署名前提下共享和改编，包括商业用途。
- CC BY-NC 论文允许在署名前提下非商业共享和改编，不得用于商业用途。
- 具体许可文本以每篇论文首页、出版社页面及论文元数据为准。
- DOI 和原刊页面见 `full-text-catalog.csv` 或站内论文卡片。
- `translations/` 中的简体中文文件为非官方机器辅助译本，已进行食品加工术语校正。译本不是出版社官方版本，图表、公式、表格和关键数值请优先核对英文原文。
- CC BY-NC 论文的中文译本同样受非商业限制，仅可按原许可非商业使用并保留作者署名。

本页不提供绕过付费墙获取的版本，也不代表原作者或出版社对本站作额外背书。
