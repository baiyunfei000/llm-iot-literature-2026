# 牛肉风干制品开放全文精选

本页面收录 15 篇与牛肉干、风干牛肉、Biltong 和 Pastirma 相关的开放获取论文。所有 PDF 均已完成文件完整性、页数和浏览器打开验证。

## 使用

直接打开 GitHub Pages 页面，通过标题、作者、期刊或 DOI 搜索，点击“在线阅读 PDF”即可阅读。

## 文件

- `pdfs/`：15 篇完整论文
- `thumbs/`：论文首页缩略图
- `full-text-catalog.csv`：文献目录
- `full-text-library.bib`：BibTeX 引文库
- `catalog.json`：结构化元数据
- `NOTICE.md`：论文来源与许可说明

## 许可

论文分别采用 CC BY、CC BY-NC 等开放获取许可。非商业许可论文不得用于商业用途。每篇论文的作者、DOI、来源与许可字段见目录和 `NOTICE.md`。
