# 牛肉风干制品开放全文精选

本页面收录 15 篇与牛肉干、风干牛肉、Biltong 和 Pastirma 相关的开放获取论文，并配套 15 份完整简体中文译本。所有 PDF 均已完成文件完整性、页数和浏览器打开验证。

## 使用

直接打开 GitHub Pages 页面，通过标题、作者、期刊或 DOI 搜索，可分别选择“简体中文全译”或“英文原文”。

## 文件

- `pdfs/`：15 篇完整论文
- `translations/`：15 份简体中文全译
- `all-15-papers-zh-CN.pdf`：127 页中文全译合集
- `chinese-translations.zip`：中文译本打包下载
- `thumbs/`：论文首页缩略图
- `full-text-catalog.csv`：文献目录
- `full-text-library.bib`：BibTeX 引文库
- `catalog.json`：结构化元数据
- `NOTICE.md`：论文来源与许可说明

## 许可

论文分别采用 CC BY、CC BY-NC 等开放获取许可。非商业许可论文不得用于商业用途。每篇论文的作者、DOI、来源与许可字段见目录和 `NOTICE.md`。

简体中文文件为机器辅助翻译并做食品加工术语校正，属于非官方译本。图表、公式、表格和关键数值请以英文原文为准。
